# Konzolni kalkulator

Preprost konzolni kalkulator v Pythonu, ki prek argumentov v ukazni vrstici
izvede osnovne računske operacije (seštevanje, odštevanje, množenje, deljenje).
Projekt je nastal kot testni projekt za vajo iz nadzora verzij z Gitom.

## Zahteve

- Python 3

## Namestitev

```bash
git clone git@github.com:LukasZid/vaja1.git
cd vaja1
```

## Uporaba

```bash
python calc.py <stevilo1> <operator> <stevilo2>
```

Operatorji: `+`, `-`, `*`, `/`

### Primeri

```bash
python calc.py 5 + 3      # Rezultat: 8.0
python calc.py 10 - 4     # 6.0
python calc.py 3 * 5      # 15.0
python calc.py 6 / 3      # 2.0
```

## Funkcionalnosti

- Seštevanje, odstevanje, množenje in deljenje
- Preverjanje deljenja z nič
- Preverjanje pravilnega števila argumentov
